# SystemVerilog Clock Generator Verification Utility

Built a configurable clock generator utility in SystemVerilog with support for frequency, duty cycle, and phase shift control.

This project helped me practice:
- Timing calculations
- Reusable verification tasks
- Waveform analysis
- SystemVerilog testbench development

## Features
- Configurable frequency
- Adjustable duty cycle
- Phase shift support
- Reference clock synchronization
- VCD waveform dumping

## Tools Used
- SystemVerilog
- GTKWave
- Vivado / ModelSim
